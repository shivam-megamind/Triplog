# Project instructions

- Build one approved milestone at a time and stop for review after validation.
- AI may organize a traveler’s material, but must never invent memories, opinions, warnings, or recommendations.
- Trips are private by default. Public pages must expose only explicitly published material.
- Do not add dependencies without approval.
- Run `npm run test`, `npm run lint`, `npm run typecheck`, and `npm run build` for implementation milestones.
- Keep `SCOPE.md`, `PLAN.md`, and `TEACH.md` current when behavior or decisions change.
- End each meaningful milestone with a plain-language teach-back.
